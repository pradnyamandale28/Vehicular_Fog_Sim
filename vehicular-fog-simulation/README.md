# Vehicular Fog Simulation

This project simulates vehicular movement in foggy conditions, providing insights into how fog affects driving behavior and vehicle dynamics.

## Project Structure

```
vehicular-fog-simulation
├── src
│   ├── simulation
│   │   └── main.py          # Main entry point for the simulation
│   ├── runners
│   │   └── runner.py        # Logic for running the simulation
├── results
│   └── README.md            # Documentation for simulation results
├── backup
│   └── old_code
│       └── README.md        # Information on backed up old code
├── requirements.txt         # List of project dependencies
└── README.md                # Overview of the project
```

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   cd vehicular-fog-simulation
   ```

2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage Guidelines

- To run the simulation, execute the `runner.py` script located in the `src/runners` directory.
- Modify parameters in `runner.py` to customize the simulation settings.
